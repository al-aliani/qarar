## منصة الهيمنة الرقمية لدراسات الجدوى وإدارة الأعمال (2026–2036)

هذه المجلد يحتوي على تنفيذ تدريجي لخارطة طريق الهيمنة الرقمية على مدى 10 سنوات، مع التركيز أولاً على:

- **العقل الداخلي المتكامل (سنوات 1–2)**: 
  - منصة دراسات جدوى ذكية.
  - محرك مالي (NPV, IRR, Payback, Breakeven, Margins).
  - تجميع بيانات المشاريع في `Experience Brain`.
- **باقي المراحل** سيتم تمثيلها كخدمات ووحدات يمكن تطويرها لاحقاً:
  - المدير التنفيذي الذاتي (3–5).
  - النظام البيئي الوطني (6–8).
  - وزارة الاقتصاد الرقمية (9–10).

### هيكل المجلد

- `backend/`:
  - نواة الـ API والخدمات (محرك مالي، محلل ميداني، ...).
- `docs/`:
  - وثائق الرؤية وخارطة الطريق العشرية.

### متطلبات أولية لتشغيل الـ backend (مقترحة)

- Python 3.11+
- حزم (سيتم وضعها في `requirements.txt` لاحقاً):
  - fastapi
  - uvicorn
  - pydantic
  - numpy

### الخطوة التالية

- بناء نواة backend بسيطة:
  - نقاط نهاية (APIs) لحساب NPV و IRR و Payback.
  - نقطة نهاية مبدئية لـ Field Analyst.
  - تخطيط تجميعي لبيانات المشاريع (Experience Brain v1).

# 📊 Feasibility Study Platform (FeasSimulator)

منصة تفاعلية متقدمة لإنشاء دراسات الجدوى الاقتصادية، مصممة لمساعدة رواد الأعمال والمستثمرين على اتخاذ قرارات مدروسة بناءً على بيانات دقيقة ونمذجة مالية متطورة.

## 🌟 الميزات الرئيسية

### 1. المحرك المالي (Financial Engine) 🧮
- نمذجة مالية متكاملة (CAPEX, OPEX, Revenue).
- قوائم مالية معيارية (دخل، تدفقات نقدية، ميزانية عمومية).
- مؤشرات أداء دقيقة (NPV, IRR, ROI, Payback Period).
- تحليل الحساسية وتخطيط السيناريوهات.

### 2. الذكاء الاصطناعي (AI Integration) 🤖
- **توليد تلقائي**: ملخصات تنفيذية، تحليل SWOT، استراتيجيات تسويقية.
- **مساعد ذكي**: اقتراح حملات إعلانية، تحليل منافسين، وتقدير إيرادات.
- **نظام هجين**: يعمل مع خادم Python محلي (Llama/GPT) أو وضع Offline ذكي.

### 3. أدوات التصدير والمشاركة 📥
- **تصدير PDF**: تقرير احترافي جاهز للطباعة.
- **تصدير Excel**: ملفات مفصلة بالمعادلات والقوائم المالية.
- **تقرير بنكي**: عرض مخصص للمؤسسات التمويلية.
- **حفظ/تحميل JSON**: إمكانية حفظ المشاريع ومشاركتها بسهولة.

#### قريباً: ميزات التصدير المتقدمة 🚀
- **PowerPoint (PPTX)**: عروض تقديمية احترافية (10 شرائح)
- **Word (DOCX)**: تقارير قابلة للتعديل (20-30 صفحة)
- **QR Code**: مشاركة سريعة بالمسح
- **إرسال بالبريد**: مشاركة التقرير مباشرة
- **نسخ مشروع**: استنساخ دراسة كاملة
- **سلة المحذوفات**: حذف آمن مع استرجاع

> للمطورين: راجع `docs/FEATURES_SUMMARY.md` للتفاصيل الكاملة

### 4. تجربة المستخدم (UX) 🚀
- واجهة Wizard تفاعلية ترشدك خطوة بخطوة.
- لوحة قيادة حية (Active Dashboard) تعرض النتائج فورياً.
- دعم كامل للغة العربية (RTL).
- فحص جودة البيانات (QA Gate) للتنبيه على المدخلات غير المنطقية.

## 🛠️ دليل التشغيل وتثبيت المشروع

### المتطلبات
- **Node.js** (لتشغيل الواجهة)
- **Python 3.x** (اختياري - لخادم الذكاء الاصطناعي)

### التشغيل السريع

1. **تشغيل الواجهة (Frontend):**
   ```bash
   npm install
   npm run dev
   ```
   سيفتح الموقع على: `http://localhost:5173`

2. **تشغيل خادم الذكاء الاصطناعي (AI Server - اختياري):**
   ```bash
   python ai_server.py
   ```
   يعمل على المنفذ: `8080`

> **ملاحظة:** إذا لم تشغل خادم Python، سيعمل النظام في وضع **Offline Mode** ويقدم نتائج افتراضية ذكية.

### الحفظ السحابي والمصادقة (اختياري)

لتفعيل تسجيل الدخول والحفظ على السحابة، أعد مشروع **Supabase** (جداول + RLS + متغيرات). التفاصيل الكاملة في **[docs/إعداد_Supabase.md](docs/إعداد_Supabase.md)**. بدون Supabase تعمل المنصة **محلياً فقط** (المسودة تُحفظ على جهازك).

## 🔄 سير العمل (Workflow)

1. **التعريف**: إدخال معلومات المشروع والسوق.
2. **الفني والتشغيلي**: تحديد التكاليف الرأسمالية والتشغيلية.
3. **المالي**: هيكلة التمويل والقروض.
4. **التحليل**: مراجعة المؤشرات، السيناريوهات، والمخاطر.
5. **القرار**: الحصول على توصية (GO / NO-GO) وتصدير الدراسة.
