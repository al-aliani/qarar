# معايير صارمة لقالب دراسة الجدوى (QA Standards)

هذه المعايير تُعامل كـ **Gate**: إذا فشل أي بند “حرِج” فالدراسة **غير صالحة لاتخاذ قرار** حتى يتم الإصلاح.

## 1) معايير هيكلية (Structure) — حرِجة
- [ ] أسماء الشيتات **لا تحتوي** فراغات بداية/نهاية (Trim-safe).
- [ ] لا يوجد اسمان مكرران بعد Trim.
- [ ] وجود الشيتات الإلزامية:  
  `00_Cover`, `01_Assumptions`, `03_RevenueDrivers`, `04_Opex`, `05_Capex`, `10_IncomeStatement`, `11_CashFlow`, `20_KPIs`, `21_Scenarios`, `22_Sensitivity`, `30_Risks`, `40_Dashboard`, `99_Audit`.

## 2) معايير سلامة الصيغ (Formula Integrity) — حرِجة
- [ ] **0** مراجع خارجية في الصيغ (أي صيغة تحتوي `[ ... ]` = Fail).
- [ ] **0** ظهور لـ `#REF!` داخل الصيغ (حتى لو لم يظهر كقيمة).
- [ ] **0** قيم أخطاء Excel: `#VALUE!`, `#DIV/0!`, `#N/A`, `#NAME?`, `#NUM!`, `#REF!`.
- [ ] ممنوع استخدام دوال متطايرة في طبقة الحسابات: `NOW/TODAY/RAND/RANDBETWEEN/OFFSET/INDIRECT`.

## 3) معايير المدخلات (Inputs) — حرِجة
- [ ] كل مدخل رقمي مستخدم بالحساب هو **رقم فعلي** (ليس نص مثل “30 ريال/شهر”).
- [ ] جميع الثوابت (نسب/معدلات/خصم/ضريبة/نمو/تحويل) تأتي من `01_Assumptions` عبر **Named Ranges**.
- [ ] لا يوجد رقم “مُضمّن” داخل الصيغ لغير الضرورة (Hardcoded constants). الاستثناء الوحيد: عوامل تحويل واضحة مثل `*12` (شهري→سنوي).

## 4) معايير القرار (Decision-Readiness) — حرِجة
- [ ] `20_KPIs` ينتج: **NPV + IRR + Payback + Breakeven + Margins**.
- [ ] يوجد قرار تلقائي: **GO / NO-GO / REVISE** مبني على Thresholds واضحة في `01_Assumptions`.
- [ ] `21_Scenarios` يحتوي Base/Best/Worst على الأقل، مع تعريف ما الذي تغير (وبكم) بشكل قابل للتدقيق.
- [ ] `22_Sensitivity` يختبر على الأقل السعر/الطلب/التكاليف/Capex/الخصم.

## 5) معايير المخاطر (Risk) — مهمة
- [ ] `30_Risks` يحتوي: احتمال/أثر/تخفيف/مالك/موعد.
- [ ] تحديد “Kill Risks” وربطها بتوصية القرار.

## 6) معايير التوثيق (Documentation) — مهمة
- [ ] كل بند رئيسي في Opex/Capex لديه مصدر تقدير (Quote/Benchmark/Assumption) أو ملاحظة تبريرية.
- [ ] `00_Cover` يذكر ما لا يغطيه النموذج (Out of Scope).

## 7) نتيجة التدقيق (QA Verdict)
- **PASS**: كل البنود الحرِجة ناجحة.
- **FAIL**: أي بند حرِج فشل.
- **PASS WITH NOTES**: البنود الحرِجة ناجحة لكن توجد ملاحظات تحسين.
