# 🧪 دليل اختبار محاكاة تجربة المستخدم

## طرق الاختبار المتوفرة

### 1. اختبار تفاعلي في المتصفح 🌐

**الملف:** `test_ux_simulation.html`

**كيفية الاستخدام:**
1. افتح الملف في المتصفح
2. اضغط زر "🚀 بدء الاختبار"
3. شاهد النتائج مباشرة

**المميزات:**
- ✅ يعمل مباشرة في المتصفح
- ✅ لا يحتاج تثبيت إضافي
- ✅ واجهة جميلة وواضحة
- ✅ يعرض النتائج فوراً

---

### 2. اختبار تلقائي مع Puppeteer 🤖

**الملف:** `test_ux_automated.js`

**المتطلبات:**
```bash
npm install puppeteer
```

**كيفية الاستخدام:**
```javascript
const puppeteer = require('puppeteer');
const { runUXSimulation } = require('./test_ux_automated.js');

(async () => {
    const browser = await puppeteer.launch({ headless: false });
    const page = await browser.newPage();
    await page.goto('http://localhost:5173'); // رابط التطبيق
    await runUXSimulation(page);
    await browser.close();
})();
```

**المميزات:**
- ✅ اختبار تلقائي كامل
- ✅ يمكن دمجه في CI/CD
- ✅ يفتح المتصفح ويختبر فعلياً

---

## ما يتم اختباره؟

### ✅ الأزرار المختبرة:

1. **أزرار التنقل:**
   - السابق/التالي
   - التنقل بين الخطوات

2. **أزرار الإجراءات:**
   - حفظ/تحميل
   - تصدير (PDF/Excel/JSON)
   - حذف/إضافة

3. **أزرار الذكاء الاصطناعي:**
   - اقتراحات AI
   - توليد تلقائي

4. **أزرار المحاكاة:**
   - تشغيل مونت كارلو
   - محاكاة التشغيل

## النتائج المتوقعة

### ✅ نجاح:
- الزر موجود في DOM
- الزر مرئي وغير معطل
- الزر لديه Event Listener
- النقر يعمل بدون أخطاء

### ⚠️ تحذير:
- الزر موجود لكن معطل
- الزر مخفي
- لا يوجد Event Listener

### ❌ فشل:
- الزر غير موجود
- خطأ عند النقر
- خطأ في JavaScript

## إصلاح المشاكل

### إذا فشل زر:
1. افتح Console (F12)
2. ابحث عن الأخطاء
3. تحقق من:
   - وجود الزر في DOM
   - ربط Event Listener
   - عدم وجود أخطاء JavaScript

### إذا كان الزر معطل:
- تحقق من الشروط (validation)
- تأكد من وجود البيانات المطلوبة
- راجع الكود في `bindEvents()`
