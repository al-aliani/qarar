# سياسة الخصوصية — محاكي الجدوى (FeasSimulator)

**آخر تحديث:** يناير 2026

## 1. نطاق التطبيق

تنطبق هذه السياسة على منصة دراسة الجدوى الذكية (محاكي الجدوى) والبيانات التي يجمعها أو يعالجها التطبيق.

## 2. البيانات التي نجمعها

- **بيانات الحساب:** البريد الإلكتروني وكلمة المرور (مُخزّنة بشكل آمن عبر Supabase).
- **بيانات الدراسة:** محتوى دراسات الجدوى التي تنشئها (محلياً أو سحابياً حسب إعداداتك).
- **بيانات تقنية:** عنوان IP، نوع المتصفح، وبيانات الاستخدام اللازمة لتشغيل الخدمة وتحسينها.

## 3. كيفية استخدام البيانات

- تقديم الخدمة والحفظ والمزامنة.
- تحسين المنتج وتحليل الاستخدام (بدون تحديد هوية).
- الالتزام بالالتزامات القانونية.

## 4. المشاركة مع أطراف ثالثة

لا نبيع بياناتك. قد نشارك بيانات مجمّعة أو مُجهولة الهوية لأغراض تحليلية أو عند الالتزام القانوني.

## 5. حقوقك (GDPR والمملكة)

يمكنك طلب الوصول إلى بياناتك أو تصحيحها أو حذفها. للتمارين على حقوقك، راسلنا عبر البريد المذكور في التطبيق.

## 6. الأمان

نستخدم تشفيراً في النقل (TLS) وحماية مناسبة للبيانات المُخزّنة. المصادقة عبر Supabase مع أفضل الممارسات.

## 7. التحديثات

قد نحدّث هذه السياسة. سنُعلمك بالتغييرات الجوهرية عبر التطبيق أو البريد.
