# دليل التشغيل الموحد — محاكي الجدوى

> **الغرض:** توحيد طريقة تشغيل المشروع وتوثيق المنافذ

---

## المنافذ (Ports)

| الخدمة | المنفذ | الوصف |
|--------|--------|-------|
| **Vite (Frontend)** | 5173 | الواجهة الأمامية — الوصول عبر http://localhost:5173 |
| **AI Server (Backend)** | 8080 | خادم الذكاء الاصطناعي — يستقبل الطلبات على /api/* |

---

## التشغيل الموحد (طريقة واحدة)

### Windows (المُوصى به)

```batch
# تشغيل كلا الخدمتين معاً
start_all.bat
```

**ماذا يحدث:**
1. يبدأ خادم AI (Python) على المنفذ 8080 في نافذة منفصلة
2. يبدأ Vite على المنفذ 5173 ويفتح المتصفح تلقائياً

### PowerShell

```powershell
# 1. تشغيل خادم AI في الخلفية
.\serve_local.ps1

# 2. في نافذة أخرى — تشغيل الواجهة
npm run dev
```

### يدوياً (نافذتان)

```bash
# النافذة 1 — خادم AI
python ai_server_enhanced.py

# النافذة 2 — الواجهة
npm run dev
```

---

## الـ Proxy (توجيه API)

Vite يُوجّه طلبات `/api/*` تلقائياً إلى http://localhost:8080:

```javascript
// vite.config.js
proxy: {
  '/api': {
    target: 'http://localhost:8080',
    changeOrigin: true,
    secure: false,
  },
}
```

**ملاحظة:** لا تستخدم `python -m http.server` على المنفذ 5173 — مخصص لـ Vite.

---

## التحقق من التشغيل

1. افتح http://localhost:5173 — يجب أن تظهر الواجهة
2. إذا ظهرت أخطاء CORS أو 404 لـ `/api/*` — تأكد أن خادم AI يعمل على 8080
3. للتوقف: اضغط Ctrl+C في كل نافذة
