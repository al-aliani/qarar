# دليل التكاملات — خطوة بخطوة

استخدم هذا الملف لتتبع التكاملات واحدة تلو الأخرى. ضع ✅ بجانب ما أنجزته.

---

## التكامل 1: Supabase (المصادقة + الحفظ السحابي)

### الخطوة 1.1 — إنشاء مشروع Supabase
- [ ] ادخل إلى https://supabase.com وسجّل الدخول (أو أنشئ حساباً).
- [ ] اضغط **New Project**.
- [ ] اختر **Organization** (أو أنشئ واحدة).
- [ ] **Name:** مثلاً `feasibility-platform`.
- [ ] **Database Password:** اختر كلمة مرور قوية ** واحفظها** (ستحتاجها للاتصال بقاعدة البيانات لاحقاً).
- [ ] **Region:** اختر الأقرب لك (مثلاً Frankfurt أو Singapore).
- [ ] اضغط **Create new project** وانتظر حتى يكتمل الإعداد (دقيقة أو اثنتين).

### الخطوة 1.2 — نسخ المفاتيح
- [ ] من القائمة الجانبية: **Project Settings** (أيقونة الترس).
- [ ] من القائمة الفرعية: **API**.
- [ ] انسخ واحفظ في مكان آمن:
  - **Project URL** → هذا هو `SUPABASE_URL`
  - **anon public** (تحت "Project API keys") → هذا هو `SUPABASE_ANON_KEY`
- [ ] **لا تنسخ** `service_role` — لا تستخدمه في الواجهة أبداً.

### الخطوة 1.3 — إنشاء الجداول
- [ ] من القائمة الجانبية: **SQL Editor**.
- [ ] اضغط **New query**.
- [ ] افتح الملف `docs/supabase_schema.sql` في المشروع.
- [ ] انسخ **كل** محتوى الملف (من أول سطر إلى آخر سطر — بدون أي أسطر Markdown مثل \`\`\`).
- [ ] الصق في محرر SQL في Supabase.
- [ ] اضغط **Run** (أو Ctrl+Enter).
- [ ] تأكد أن الرسالة "Success" تظهر بدون أخطاء.

### الخطوة 1.4 — إعطاء المنصة المفاتيح (تطوير محلي)
- [ ] افتح موقعك المحلي (مثلاً http://localhost:5173 أو حيث تشغّل المنصة).
- [ ] افتح أدوات المطوّر **F12** → تبويب **Console**.
- [ ] الصق الأمر التالي (واستبدل القيم الحقيقية):

```javascript
localStorage.setItem('SUPABASE_URL', 'https://XXXX.supabase.co');
localStorage.setItem('SUPABASE_ANON_KEY', 'eyJhbGc...المفتاح_الكامل');
```

- [ ] اضغط Enter ثم حدّث الصفحة **F5**.

### الخطوة 1.5 — التحقق
- [ ] في المنصة اضغط "دخول / تسجيل".
- [ ] سجّل حساباً جديداً (بريد + كلمة مرور).
- [ ] أنشئ دراسة أو عدّل واحدة، ثم انتظر الحفظ.
- [ ] تحقق أن الشريط الجانبي يظهر **"● محفوظ في السحابة"**.
- [ ] أغلق المتصفح وافتح المنصة مرة أخرى — يجب أن تظهر الدراسة في القائمة وتُحمّل من السحابة.

## التكامل 2: تسجيل الدخول بـ Google (اختياري)

**التفاصيل الكاملة:** راجع **[إعداد Supabase — القسم 6](إعداد_Supabase.md#6-تفعيل-تسجيل-الدخول-بـ-google-oauth)** (خطوات Google Cloud Console + Supabase).

- [ ] في [Google Cloud Console](https://console.cloud.google.com/apis/credentials): أنشئ OAuth 2.0 Client ID (نوع **Web application**).
- [ ] أضف **Authorized redirect URI:** `https://YOUR_PROJECT_REF.supabase.co/auth/v1/callback` (استبدل YOUR_PROJECT_REF بمعرّف مشروع Supabase).
- [ ] انسخ **Client ID** و **Client Secret**.
- [ ] في Supabase: **Authentication → Providers** → فعّل **Google** → الصق المفتاحين.
- [ ] في **Authentication → URL Configuration** ضع **Site URL** (مثلاً `http://localhost:5173` للتطوير).
- [ ] جرّب في المنصة زر «تسجيل بحساب Google» (يوجّهك لصفحة Google ثم يعود ويسجّل الدخول).

## التكامل 3: reCAPTCHA (اختياري — حماية من البوتات)

- [ ] ادخل إلى https://www.google.com/recaptcha/admin.
- [ ] سجّل موقعك، اختر reCAPTCHA v3.
- [ ] انسخ **Site Key**.
- [ ] في Console المتصفح: `localStorage.setItem('RECAPTCHA_SITE_KEY', 'موقعك_Site_Key');`
- [ ] (للمرحلة المتقدمة: إعداد التحقق بالسيرفر باستخدام Secret Key.)

---

## التكامل 4: Google Sheets (اختياري — تصدير لجدول)

- [ ] إنشاء Google Apps Script Web App حسب التعليمات في `web/js/services/GoogleSheetsService.js` أو وثيقة التكامل.
- [ ] حفظ URL النشر في: `localStorage.setItem('GOOGLE_SHEETS_WEB_APP_URL', 'الرابط');`

---

## التكامل 5: Google Analytics 4 (اختياري — تحليلات)

- [ ] إنشاء Property في [Google Analytics](https://analytics.google.com/) والحصول على Measurement ID.
- [ ] إضافة كود gtag في الصفحة الرئيسية وربط أحداث المنصة (راجع `docs/INTEGRATION_FEATURES.md`).
