# دليل البدء السريع — محاكي الجدوى

## التشغيل المحلي

1. **التثبيت**
   ```bash
   npm install
   ```

2. **تشغيل الواجهة**
   ```bash
   npm run dev
   ```
   ستُفتح المنصة على `http://localhost:5173` (أو المنفذ الظاهر في الطرفية).

3. **تشغيل خادم الذكاء الاصطناعي (اختياري)**
   ```bash
   python ai_server.py
   ```
   للاستفادة من توليد النصوص والتحليلات المحسنة.

---

## رحلة المستخدم الأساسية

1. **اختيار قالب** — ابدأ من قالب قطاعي (مطعم، مقهى، صالة رياضية...) أو املأ من الصفر.
2. **معلومات المشروع** — الاسم، المدينة، الفكرة، المساحة.
3. **الدراسة الفنية** — المعدات، الأثاث، المباني.
4. **الموارد البشرية** — الوظائف والرواتب.
5. **مصادر الإيرادات** — العملاء/شهر، متوسط السعر، تكلفة متغيرة.
6. **التمويل** — التمويل الذاتي، القرض البنكي (إن وُجد).
7. **الافتراضات** — معدل الخصم، التضخم، العملة (SAR، AED، KWD...).
8. **لوحة القرار** — عرض NPV، IRR، فترة الاسترداد، والقرار الاستثماري.

## الحفظ والتصدير

| الإجراء        | الوصف                               |
|----------------|--------------------------------------|
| حفظ الدراسة   | حفظ كـ JSON محلياً أو سحابياً (إن وُجد تسجيل دخول) |
| تحميل دراسة   | استيراد JSON سابق                    |
| استيراد من CSV| دمج بيانات أساسية من ملف CSV        |
| تصدير PDF     | تقرير شامل للطباعة                  |
| تصدير Excel   | قوائم مالية مفصلة                   |
| تقرير بنكي    | نموذج لبنك التنمية وبرامج التمويل   |
| Pitch Deck     | شرائح للمستثمرين                    |
