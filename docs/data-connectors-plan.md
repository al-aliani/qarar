# استشارة «قرار»: تغذية أدوات المساندة ببيانات حقيقية
**بحث سرب مُتحقَّق · 2026-07-06** · (18 وكيل · 47 مصدر مرشّح → 7 مؤكّدة، 3 مدحوضة · تحقّق عدائي حيّ على الويب)

## (1) الرأي المباشر

نعم، خطوة صحيحة لـ«قرار» — لكن العائد الحقيقي **تسويقي/مصداقي لا تقني**. اليوم المستخدم يكتب «حجم السوق» و«نمو القطاع» و«التضخم» بالتخمين الأعمى، وأنت تبيع «دراسة عالية الجودة» — تناقض قاتل مع مبدأ الجودة أولًا. أي مدقق بنكي يكتشف الأرقام المخترعة بدقائق. وسم القيمة بمصدر («GASTAT — تعداد 2022») ينقل الدراسة من «Excel مُقنّع» إلى «وثيقة قابلة للدفاع أمام جهة تمويل».

**واقعية التوقّعات:** المصادر المجانية عالية القيمة (GASTAT, OSM) تغذّي الاقتصاد الكلي/الديموغرافيا/عدّ المنافسين — أرقام بطيئة الحركة تحتاج **لقطة مُجمّعة (snapshot) تُحدَّث ربع سنوي، لا API حيّة**. الحقول الأصعب (footfall، عملاء المنافس/يوم، أسعار قوائم التوصيل) **لا مصدر قانوني لها** — تُسقَط أو تتحوّل لتقديرات مُشتقّة موسومة، لا تُخمَّن.

**القيد الحاكم:** التزام PDPL و«لا مفاتيح في العميل» (نجّاك من ثغرة تسريب المفاتيح سابقًا). أي API مُفتاحية **يجب** أن تمرّ عبر proxy خادمي؛ البيانات المُجمّعة لا تلمس هذا القيد أصلًا — سبب إضافي لتفضيلها.

**الخلاصة:** افعلها، وابدأ بالمجاني المُجمّع (Python → JSON) لا بالـ API الحيّة.

## (5) المعمارية المقترحة

طبقة `DataConnectors` جديدة تُغذّي `FieldSuggestionService` و`SmartAdvisor`، بثلاثة مبادئ غير قابلة للتفاوض: **لا مفاتيح بالعميل، لقطات محلية للبيانات المفتوحة، ووسم مصدر على كل قيمة**.

1. **`DataConnectors` — واجهة موحّدة:** `suggest(field, context)` تُرجع دائمًا كائنًا موسومًا `{ value, source, year, provenance }` لا رقمًا عاريًا. تُخفي هل المصدر مُجمّع أم proxy.
2. **`BundledSnapshots` — المسار المفضّل:** كل البيانات المفتوحة البطيئة (GASTAT, HIES, STA, OSM density) تُحوَّل offline بـ Python إلى JSON مُجمّع ويُشحن مع التطبيق (نموذج `SaudiDemographics.json` القائم). Python يتفوّق هنا: الأرقام ربع سنوية، البوابات SPA/WAF تكسر الاستدعاء الحيّ، ولا مفاتيح/CSP.
3. **`KeyedProxyClient` + Server Proxy — للـ API المُفتاحية فقط:** Google Places (وOverpass عند الحمل) يُستدعى حصرًا عبر `/api/...` على خادم Python يحمل المفتاح. **لا مفتاح يلمس العميل** — يربط مباشرة بتدقيق تسريب المفاتيح السابق. الخادم يفرض حدود المعدّل/التخزين وقيود Places.
4. **وسم المصدر على كل قيمة:** شارة مرئية بالويزارد «مصدر: GASTAT 2022» مقابل «افتراض المستخدم» مقابل «مُشتقّ». هذا ما يحفظ المصداقية ويميّزك عمّن يبيع أرقامًا مخترعة.

**Python يتفوّق:** كل المصادر الحكومية (بطيئة + بوابات مكسورة). **API حيّة تلزم فقط:** عدّ منافسين وقت إنشاء الدراسة (OSM Overpass، وGoogle Places لاحقًا).

## (6) الخطة المرحلية

**المرحلة 1 — مكاسب مجانية عالية الثقة (ابدأ هنا · أيام):** بلا مفاتيح/خادم/CSP.
1. `BundledSnapshots` من GASTAT (Python ETL) — يستبدل 40%/8% الأعمى بأرقام حقيقية ويملأ `tam.source/year`.
2. استبدال CompetitorScout بـ **OSM Overpass حقيقي** — عدّ/قائمة مطاعم الحي (`amenity=restaurant/fast_food/cafe`) مع «© OpenStreetMap contributors».
3. جداول رسوم بلدية/سجل تجاري/دفاع مدني منشورة كـ JSON موسوم → خطاف «🪄 جلب التراخيص».
4. معدّلات ثابتة منشورة (GOSI، نطاقات السعودة) كافتراضات نظامية موسومة.
5. CPI + GDP من World Bank (API CC-BY) لملء `inflationRate` بدل 0.02 الأعمى.

**المرحلة 2 — APIs مُفتاحية خلف proxy (بعد إثبات القيمة):**
6. بناء Server Proxy (Python) يحمل المفاتيح خادميًا (أصلح المشغّل ليُشغّله فعلًا).
7. Google Places بحذر خلف الـ proxy — احفظ الرقم المُشتقّ فقط (Aggregate COUNT). **أسقط `estimatedDailyCustomers` نهائيًا.**
8. Overpass مُستضاف ذاتيًا إن تجاوز الحمل ~10k طلب/يوم.

**المرحلة 3 — بيانات مدفوعة/شراكات (عند طلب مؤكّد):**
9. Foursquare OS Places كطبقة كثافة إضافية للأحياء التي يضعف فيها OSM.
10. شراكات إيجار/أجور (Ejar/REGA) لدقّة موقعية — فقط إن دفع العملاء مقابلها.

**المبدأ الحاكم:** لا تنتقل لمرحلة قبل أن تُثبت السابقة قيمتها. المرحلة 1 وحدها قد تكفي لنقل «قرار» من «أرقام مخترعة» إلى «دراسة قابلة للدفاع».
