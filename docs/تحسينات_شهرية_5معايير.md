npm run test:e2e:all-browsers

## CI

- **الملف**: `.github/workflows/e2e.yml`
- يشغّل E2E على Chromium و Firefox و WebKit عند الدفع أو فتح PR على `main`/`master`.
- في حال الفشل يُرفع تقرير Playwright كـ artifact.
- **اختبارات بصرية في CI**: تحتاج لقطات أساسية مُحمّلة مسبقاً. من المحلي: `npm run test:e2e -- e2e/visual.spec.js --update-snapshots` ثم commit مجلد اللقطات (مثلاً `e2e/visual.spec.js-snapshots/`).
