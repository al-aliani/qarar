### 1.2 الحفظ السحابي الأساسي ✅ (مُنجَز — يعمل عند تسجيل الدخول)

| المعيار | الحالة | الملف / الملاحظة |
|---------|--------|-------------------|
| حفظ تلقائي دوري | ✅ | `autoSave.js` — كل 30 ثانية |
| حفظ محلي (مسودة) | ✅ | `store.js` → mac_blash_study_v2 + `PersistenceService` → feas_project_* |
| مزامنة مع السحابة عند تسجيل الدخول | ✅ | `PersistenceService.save()` → Supabase `studies` + `study_inputs` |
| تحميل من السحابة عند فتح المشروع | ✅ | `PersistenceService.load()` — Cloud أولاً ثم Local |
| قائمة مشاريع (محلي + سحابي) | ✅ | `PersistenceService.listHeaders()` |
| مؤشر حالة الحفظ | ✅ | `store.getLastSaveStatus()` + `Sidebar.updateSaveStatus()` |

**ما يلزم للمرحلة 1:**
- [x] ربط AutoSave بعرض حالة المزامنة (محلي / سحابي) في الشريط الجانبي — تم عبر استدعاء `store.save()` من AutoSave لتفعيل `_syncToCloud` وتحديث `_lastSaveStatus`.

### 1.3 تفعيل AI الأساسي ✅ (مُنجَز — بدون مفتاح API)

| المعيار | الحالة | الملف / الملاحظة |

| توليد SWOT / PESTEL / مخاطر / جدول زمني | ✅ | `InternalAIGenerator` لكل نوع |
| اقتراحات (منافسون، شرائح، مبانٍ، معدات، إلخ) | ✅ | أزرار "اقترح" في الواجهة → InternalAIGenerator |
| دعم API خارجي (OpenAI) | ✅ | عند وجود مفتاح: `AIConnector` يوجّه للـ API |

**ما يلزم للمرحلة 1:**
- [x] التأكد من أن زر "توليد الملخص التنفيذي" واضح في لوحة القرار/الملخص ولا يتطلب مفتاح API (يعمل بالوضع الداخلي).
- [x] تلميح على الزر: "يعمل بدون مفتاح API؛ يمكنك إضافة مفتاح OpenAI لنتائج أوضح" (title على زر الملخص وزر التوليد).
