# خطة التنفيذ الشاملة: خارطة الطريق التقنية للمنصة المتكاملة

تعرض هذه الوثيقة الخطة التفصيلية لدمج جميع الميزات المطلوبة (سيناريوهات، محاكاة مونت كارلو، الكاتب الذكي، والتنفيذ) داخل البنية الحالية للمنصة.

## 1. تحديث البنية الأساسية (Foundation Upgrade)
المنصة حالياً تعتمد على `store.js` لتخزين البيانات و `app.js` للتنقل. لتحويلها إلى "محرك ذكي"، نحتاج إلى إضافة طبقة "المحرك المالي" (Financial Engine) التي تفصل منطق الحسابات عن واجهة العرض.

### المكون الجديد: `FinancialEngine.js`
*   **الوظيفة**: مسؤول عن حساب جميع المؤشرات المالية (إيرادات، تكاليف، أرباح، تدفقات) بناءً على المدخلات.
*   **الموقع**: `web/js/core/FinancialEngine.js`
*   **السمات**:
    *   `calculate(state)`: تأخذ حالة المتجر وتحسب النتائج.
    *   `applyScenario(state, factor)`: تطبق تعديلات السيناريو (مثلاً زيادة المبيعات 20%) دون تعديل البيانات الأصلية.

---

## 2. تنفيذ المراحل (التتابع الزمني)

### المرحلة 1: المحرك المالي وإدارة السيناريوهات (The Financial Heart)
**الهدف**: جعل الجداول "حية" وتفاعلية (مثل LivePlan).
1.  **إنشاء `FinancialEngine.js`**: نقل منطق الجمع والطرح من الكائنات المتفرقة إلى فئة مركزية.
2.  **تعديل `store.js`**: إضافة `calculatedResults` كجزء من الحالة (State) يتم تحديثه تلقائياً عند تغيير أي مدخل.
3.  **بناء واجهة `ScenarioAnalysis.js`**:
    *   إضافة شريط تحكم (Slider/Toggle) لتغيير نسبة الإيرادات/التكاليف.
    *   ربط الواجهة بالمحرك لإعادة الحساب فورياً عند التحريك.

### المرحلة 2: محاكاة مونت كارلو (Risk Intelligence)
**الهدف**: حساب احتمالية النجاح (مثل Oracle Crystal Ball) ولكن في المتصفح.
1.  **بناء `MonteCarloEngine.js`**:
    *   دالة `runSimulation(baseState, iterations=1000)`: تقوم بتكرار الحساب 1000 مرة مع تغيير عشوائي (Random Variation) بنسبة ±10% للمتغيرات الحرجة (السعر، الكمية).
    *   تخزين النتائج (1000 قيمة لصافي الربح) في مصفوفة.
2.  **واجهة `MonteCarloAnalysis.js`**:
    *   رسم بياني (Histogram) يوضح توزيع الأرباح المحتملة.
    *   عرض نسبة مئوية "احتمالية الربح" (Probability of Profit).

### المرحلة 3: الكاتب الذكي (AI Writer)
**الهدف**: توليد النصوص آلياً (مثل Jadwa Tech).
1.  **تجهيز الواجهة الخلفية (Backend Setup)**:
    *   بما أنك تستخدم Python محلياً، سننشئ ملف `ai_server.py` بسيط يعمل كواجهة API.
    *   يستقبل بيانات المشروع (JSON) ويرسلها لنموذج ذكي (Gemini/OpenAI) مع "تلقين" (Prompt) مخصص لدراسات الجدوى.
2.  **واجهة المستخدم**:
    *   إضافة زر "توليد بالذكاء الاصطناعي" في أقسام (السوق، الخطة التشغيلية).
    *   عند الضغط، يتم استدعاء الـ API وتعبئة حقول النص تلقائياً.

### المرحلة 4: التنفيذ والمراحل (Execution Roadmap)
**الهدف**: تتبع المشروع بعد الدراسة (مثل OnePage).
1.  **تحسين `Timeline.js`**:
    *   تحويله من مجرد جدول زمني إلى مخطط غانت تفاعلي (Gantt Chart).
2.  **توليد المراحل تلقائياً**:
    *   نكتب خوارزمية بسيطة تقترح مراحل قياسية بناءً على نوع المشروع (مثلاً: مطعم -> "استئجار"، "ديكور"، "توظيف").
