# 🔧 إصلاح الأخطاء المتكررة

## المشاكل التي تم إصلاحها

### 1. ✅ خطأ `DataService.getSmartGoalsTemplates is not a function`

**المشكلة:**
- عند الضغط على زر "اقتراح أهداف نموذجية" في صفحة الأهداف الذكية، يظهر خطأ: `DataService.getSmartGoalsTemplates is not a function`

**الحل:**
- تم إضافة الدالة `getSmartGoalsTemplates()` إلى `DataService.js`
- الدالة ترجع قائمة من 5 أهداف نموذجية جاهزة:
  - هدف مالي: تحقيق إيرادات سنوية
  - هدف تسويقي: الوصول إلى عدد عملاء شهري
  - هدف تشغيلي: تحقيق معدل رضا العملاء
  - هدف موارد بشرية: استقطاب وتدريب موظفين
  - هدف مالي: تحقيق نقطة التعادل

**الملف المعدل:**
- `web/js/services/DataService.js`

---

### 2. ✅ التنبيهات المتكررة "يرجى إدخال اسم المشروع"

**المشكلة:**
- عند التنقل بين الخطوات، يظهر تنبيه `alert` متكرر يطلب إدخال اسم المشروع
- التنبيه يظهر حتى لو كان المستخدم لا يزال في نفس الخطوة

**الحل:**
- استبدال `alert` بـ `toast` (إشعارات غير مزعجة)
- إضافة نظام `debounce` لمنع التنبيهات المتكررة:
  - تتبع آخر خطأ في التحقق (`lastValidationError`)
  - عرض التنبيه مرة واحدة فقط كل ثانيتين
  - إعادة تعيين التتبع بعد 2 ثانية للسماح بإظهار التنبيه مرة أخرى إذا لم يتم إصلاح المشكلة
- تحسين رسائل التحقق لتكون أكثر وضوحاً

**الملفات المعدلة:**
- `web/js/ui/Wizard.js`:
  - إضافة `import { toast } from '../utils/toast.js'`
  - إضافة `lastValidationError` و `validationDebounce` في constructor
  - تحسين `validateStep()`:
    - استخدام `toast.error()` بدلاً من `alert()`
    - إضافة debounce لمنع التكرار
    - دعم حقول `avgPrice` و `price` في revenue streams
