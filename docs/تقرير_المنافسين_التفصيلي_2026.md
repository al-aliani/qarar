## جدوى تك (Jadwa Tech)

**نقاط القوة (للاستنساخ):**
- دراسة جدوى في ثلاث خطوات بسيطة (معلومات المشروع → الدراسة السوقية → الدراسة الفنية).
- سعر منخفض وواضح: "ابدأ خطوتك الأولى بثقة — **49 ريال**" [(jadwa.tech)](https://jadwa.tech/)
- تحميل فوري لملف PDF بعد الإنجاز.
- مدعوم بالذكاء الاصطناعي ووفقاً للمعايير الاقتصادية السعودية.
- مناسب للجهات التمويلية والمستثمرين (ذكر منشآت، بنك التنمية).
- إصدار فوري لدراسة جدوى احترافية بصيغة PDF.

**نقاط الضعف (للهجوم):**
- لا سيناريوهات Base/Best/Worst مدمجة.
- لا تحليل حساسية تفاعلي.
- غياب "نسخة للممول" موحدة.
- إخلاء مسؤولية صريح: "لا تُعد الدراسة معتمدة رسمياً إلا بعد مراجعة الجهة التمويلية أو مكتب استشاري مرخّص" [(jadwa.tech)](https://jadwa.tech/)

**مهام الاستنساخ (بناء داخل منصتي):**
- مسار "سريع" 3 خطوات: تعريف المشروع → مدخلات أساسية → قرار وتحميل PDF.
- عرض سعر واضح أو "ابدأ مجاناً" في الصفحة الرئيسية.
- زر "تحميل PDF الآن" بعد إكمال المسار.

**مهام التفوق (مزايا أتقدم بها عليهم):**
- لوحة قرار GO/NO-GO/REVISE صريحة.
- تحليل Monte Carlo للمخاطر.
- حساسية تفاعلية فورية.
- "Funding Pack" أو نسخة للممول موحدة.

**تدفق متفوق مستلهم منهم:**
Landing → اختيار سريع/كامل → 3 خطوات → حساب النتائج → قرار + PDF فوري → Funding Pack → استشارة (Upsell).

- تسجيل/دخول: https://jadwa.tech/login
- المقالات: https://www.jadwa.tech/blog/...

## الجدوى (Aljdwa)

**نقاط القوة (للاستنساخ):**
- حزمة منتجات رقمية: جدوى تك، إستشارة تك، نموذج تك، شريك تك، الرحلات الرقمية.
- شراكات موثقة: صندوق التنمية السياحي، برنامج تطوير الصناعة والخدمات اللوجستية، الجري للإستثمار، سلاسة، منصة جادة، جامعات (الملك سعود، الأميرة نورة، الإمام محمد بن سعود)، مصنع رائد النجاح، جمعية البر.
- إثبات اجتماعي: "M0+ زوار"، "K0+ رائد أعمال"، "K0+ مستثمر"، "K0+ دراسة جدوى".
- دراسات معتمدة من الجهات التمويلية في المملكة.

**نقاط الضعف (للهجوم):**
- توزّع بين عدة منتجات (جدوى تك منفصل، استشارات، نموذج عمل).
- لا تدفق واحد واضح من "فكرة" إلى "قرار".
- التسعير غير واضح في الصفحة الرئيسية.

**مهام الاستنساخ (بناء داخل منصتي):**
- "رحلات رقمية" أو مسارات متعددة (جدوى، استشارة، نموذج).
- قسم "شركاء النجاح" بأسماء جهات (بدون ادعاء رسمي).
- أرقام إثبات اجتماعي واقعية.

**مهام التفوق (مزايا أتقدم بها عليهم):**
- تدفق واحد من الفكرة إلى القرار.
- قرار صريح GO/NO-GO.
- Funding Pack موحد للممول.

**تدفق متفوق مستلهم منهم:**
Landing → اختيار مسار (جدوى/استشارة/نموذج) → إدخال بيانات → إنشاء → نتيجة → Export → Funding Pack → Upsell استشارة.

## جدوى الأعمال (Jadwa)

**نقاط القوة (للاستنساخ):**
- إثبات اجتماعي قوي: 2958 دراسة جدوى، 750 بحثية، 1200 تسويقية، 150 إدارية.
- جهات تمويل مذكورة: بنك التنمية، صندوق التنمية الزراعية، برنامج كفالة، بنك الجزيرة.
- مراحل واضحة: طلب → تحليل → دراسة منتج → تسويقية → فنية → مالية → مراجعة → إرسال.
- قوالب دراسات جاهزة (مدرسة عالمية، معهد تدريب صحي، مول تجاري، شركة عمرة وسياحة، إلخ).

**نقاط الضعف (للهجوم):**
- لا مولد ذاتي؛ كل شيء عبر "طلب الخدمة".
- نموذج مكتب استشاري يدوي بالكامل.
- لا PDF فوري من واجهة ذاتية.

**مهام الاستنساخ (بناء داخل منصتي):**
- قسم "أرقامنا" أو قصص نجاح.
- روابط/قائمة "جهات التمويل".
- خيار "نسخة للممول" في التصدير.

**مهام التفوق (مزايا أتقدم بها عليهم):**
- مولد ذاتي بخطوات واضحة.
- PDF فوري دون انتظار استشاري.
- نسخة موحدة للمؤسسات التمويلية.

**تدفق متفوق مستلهم منهم:**
Landing → طلب خدمة أو أدوات ذاتية → تحليل → إنشاء → مراجعة → إرسال → Export → Funding Pack.

## منشآت (Monshaat)

**نقاط القوة (للاستنساخ):**
- رسمية حكومية؛ ثقة عالية.
- خدمة "حاسبة التكاليف" مجانية: تقدير الرسوم الحكومية، نقطة التعادل [(monshaat.gov.sa/ar/node/9340)](https://www.monshaat.gov.sa/ar/node/9340).
- "دليل النماذج والأدوات" (صناديق ريادة الأعمال): 21 أداة PDF (عصف ذهني، SWOT، نموذج عمل، خطة عمل، قائمة تدفق نقدي، إلخ) [(monshaat.gov.sa/ar/steps)](https://www.monshaat.gov.sa/ar/steps).
- هيكل مراحل واضح: الفكرة → بناء المنتج → التأسيس → النمو.

**نقاط الضعف (للهجوم):**
- لا مولد دراسة جدوى متكامل آلي.
- أدوات منفصلة (PDFs) وليست تطبيقاً تفاعلياً.
- حاسبة التكاليف تحتاج تسجيل دخول.

**مهام الاستنساخ (بناء داخل منصتي):**
- توثيق توافق بنية التقرير مع مكونات منشآت.
- خيار تصدير "هيكل متوافق مع متطلبات منشآت".
- رابط لصفحة منشآت في قسم الموارد.

**مهام التفوق (مزايا أتقدم بها عليهم):**
- مولد دراسة متكامل تفاعلي (وليس ملفات PDF منفصلة).
- حساسية وسيناريوهات وحساب NPV/IRR.

**تدفق متفوق مستلهم منهم:**
Landing → اختيار مرحلة (فكرة/منتج/تأسيس/نمو) → أدوات تفاعلية → إنشاء → Export → توافق منشآت.

**الصفحات والروابط:**
- الرئيسية: https://www.monshaat.gov.sa/
- حاسبة التكاليف: https://www.monshaat.gov.sa/ar/node/9340
- صناديق ريادة الأعمال: https://www.monshaat.gov.sa/ar/steps
- جدير: https://www.monshaat.gov.sa/ar/jadeer
- دليل تشغيل المتاجر: https://www.monshaat.gov.sa/guide/6520/home

## بنك التنمية الاجتماعية

**نقاط القوة (للاستنساخ):**
- ثقة رسمية كاملة.
- أرقام: 159.6 مليار مصروف، 3.2 مليون مستفيد، 1.3 مليون خدمة غير مالية.
- قصص نجاح (محمصة بيكولو، مرِن، منصة شتل).
- تمويل أفراد/منشآت/غير ربحي.

**نقاط الضعف (للهجوم):**
- لا أداة دراسة جدوى على الموقع؛ معلومات تمويل وخدمات.
- المستخدم يحتاج أداة خارجية لإعداد الجدوى.

**مهام الاستنساخ (بناء داخل منصتي):**
- قسم "الجدوى والتمويل" يشرح ربط المخرجات بطلب التمويل.
- قائمة تحقق "متطلبات التقديم للتمويل".
- تقرير "للمؤسسة التمويلية" بتنسيق واضح.

**مهام التفوق (مزايا أتقدم بها عليهم):**
- "تقرير بنكي" بتنسيق متوافق مع ما يتوقعه البنك (ملخص، DSCR، تدفقات، مخاطر).

**تدفق متفوق مستلهم منهم:**
Landing → اختيار نوع التمويل → إدخال بيانات → إنشاء جدوى → Export "تقرير بنكي" → روابط التقديم.

- مسار ذاتي 3 خطوات بدون انتظار استشاري.
- PDF فوري + نسخة للممول.

Landing → اختيار (سريع/كامل) → إدخال → إنشاء AI → نتيجة → دفع → تحميل → Upsell استشارة.
