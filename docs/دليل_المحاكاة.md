# 🎲 دليل المحاكاة في منصة دراسة الجدوى

## أنواع المحاكاة المتوفرة

### 1. محاكاة مونت كارلو (Monte Carlo Simulation) 🎲

**الموقع:** `web/js/ui/MonteCarloAnalysis.js`

**كيف تعمل:**
1. تقوم بتشغيل **1000 سيناريو** عشوائي
2. كل سيناريو يغير:
   - الإيرادات (Revenue) - تقلب ±20%
   - التكاليف (Costs) - تقلب ±16%
   - التكاليف الرأسمالية (CAPEX) - تقلب ±10%
3. تحسب NPV لكل سيناريو
4. تعرض:
   - احتمالية النجاح (NPV > 0)
   - متوسط الربح المتوقع
   - توزيع المخاطر (Histogram)

**الزر:** `#btnRunSim` في صفحة "محاكاة مونت كارلو"

**النتائج:**
- ✅ احتمالية النجاح: نسبة السيناريوهات التي حققت NPV > 0
- ✅ متوسط NPV: المتوسط الحسابي لجميع السيناريوهات
- ✅ درجة المخاطرة: منخفضة/متوسطة/عالية حسب الاحتمالية

---

### 2. محاكاة التشغيل (Operational Simulation) 🏭

**الموقع:** `web/js/ui/OperationalSim.js`

**كيف تعمل:**
1. تستخدم **نظرية الطوابير (Queueing Theory)**
2. تحاكي:
   - وصول العملاء (Arrival Rate)
   - وقت الخدمة (Service Time)
   - عدد الموظفين (Servers)
3. تحسب:
   - وقت الانتظار المتوقع
   - طول الطابور
   - ضغط الموظفين (Utilization)

**الزر:** `#btnRunSim` في صفحة "محاكاة التشغيل"

**النتائج:**
- ⏱️ معدل وقت الانتظار: بالدقائق
- 📊 طول الطابور المتوقع: عدد العملاء
- 👥 ضغط الموظفين: نسبة الاستخدام (%)

**تحذيرات:**
- 🛑 إذا كان الضغط ≥ 100%: النظام منهار
- ⚠️ إذا كان الضغط > 80%: ضغط عالٍ

   - المحاكاة البصرية (نقاط زرقاء = عملاء)
   - النتائج الحسابية
   - التحذيرات (إن وجدت)

## 📊 المعادلات المستخدمة

### مونت كارلو:
```
NPV = -CAPEX + Σ(CF_t / (1+r)^t)

حيث:
- CF_t = التدفق النقدي في السنة t
- r = معدل الخصم
- CAPEX = التكاليف الرأسمالية
```

### التشغيل (M/M/s):
```
Utilization (ρ) = λ / (s × μ)

حيث:
- λ = معدل الوصول (عميل/دقيقة)
- μ = معدل الخدمة (1/وقت_الخدمة)
- s = عدد الموظفين

Wait Time = (ρ × serviceTime) / (1 - ρ) / servers
Queue Length = λ × Wait Time
```

## ⚠️ ملاحظات مهمة

1. **محاكاة مونت كارلو:**
   - تعمل على البيانات الحالية من Store
   - تحتاج بيانات مالية كاملة (إيرادات، تكاليف)
   - النتائج تقريبية (1000 عينة)

2. **محاكاة التشغيل:**
   - إذا كان ρ ≥ 1: النظام غير مستقر
   - إذا كان ρ > 0.85: ضغط عالٍ
   - إذا كان ρ < 0.7: نظام مريح
