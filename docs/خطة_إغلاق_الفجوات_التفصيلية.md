### الأيام 5-7: الحفظ السحابي (Cloud Storage)

#### المهام التفصيلية:

**اليوم 5: هيكل قاعدة البيانات**
```sql
-- جدول المشاريع
CREATE TABLE projects (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE,
  name TEXT NOT NULL,
  sector TEXT NOT NULL,
  data JSONB NOT NULL,
  status TEXT DEFAULT 'draft', -- draft, active, archived
  last_calculated_at TIMESTAMP,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- جدول مشاركة المشاريع
CREATE TABLE project_shares (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  project_id UUID REFERENCES projects(id) ON DELETE CASCADE,
  shared_with_email TEXT NOT NULL,
  permission TEXT DEFAULT 'view', -- view, edit, admin
  created_at TIMESTAMP DEFAULT NOW()
);

-- جدول سجل التغييرات (Version History)
CREATE TABLE project_versions (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  project_id UUID REFERENCES projects(id) ON DELETE CASCADE,
  version_number INTEGER NOT NULL,
  data JSONB NOT NULL,
  change_summary TEXT,
  created_by UUID REFERENCES auth.users(id),
  created_at TIMESTAMP DEFAULT NOW()
);

-- Row Level Security
ALTER TABLE projects ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Users can only see their own projects"
  ON projects FOR ALL
  USING (auth.uid() = user_id);
```

**اليوم 6: خدمة المزامنة**

```
□ إضافة Offline-First Strategy:
  - حفظ محلي أولاً (سريع)
  - مزامنة مع السحابة في الخلفية
  - إشعار عند فشل المزامنة
  - إعادة المحاولة تلقائياً
```
