# أهداف الأداء — المرحلة 3

أهداف مقترحة لقياس أداء المنصة (يمكن قياسها عبر Lighthouse أو أدوات المتصفح).

---

## أهداف Core Web Vitals (مستهدفة)

| المؤشر | الهدف | ملاحظة |
|--------|--------|--------|
| **LCP** (Largest Contentful Paint) | < 2.5 ثانية | تحميل المحتوى الرئيسي |
| **FID / INP** (التفاعل) | < 100 مللي ثانية | استجابة أول إدخال |
| **CLS** (Cumulative Layout Shift) | < 0.1 | استقرار التخطيط |
| **TTI** (Time to Interactive) | < 3 ثوانٍ | جاهزية التفاعل |

---

## ما تم تطبيقه

- **Lazy loading للمكونات:** تحميل ديناميكي للشاشات (مثل DashboardView، ExecutiveSummary) عند الحاجة.
- **Code splitting:** بناء Vite ينتج chunks منفصلة.
- **تخزين مؤقت PWA:** Service Worker يخزن الأصول بعد أول تحميل لتسريع الزيارات التالية.
- **Debouncing:** الحفظ التلقائي والمزامنة تستخدم تأخيراً (مثلاً 1 ثانية) لتقليل العمليات المتكررة.

---

## قياس الأداء

1. **Lighthouse (Chrome DevTools):** تبويب Lighthouse → تحليل الأداء.
2. **في الإنتاج:** مراقبة LCP/CLS عبر Real User Monitoring (RUM) أو PageSpeed Insights.
