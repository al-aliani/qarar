# مصفوفة اختبارات التصدير (5 حالات)

> **الغرض:** التأكد من استقرار التصدير (PDF، PPTX، DOCX، Excel) قبل اعتباره DoD

---

## الحالات الخمس

| # | الحالة | الوصف | المدخلات | النتيجة المتوقعة |
|---|--------|-------|----------|------------------|
| 1 | **عربي** | نص عربي كامل، أسماء عربية طويلة | projectInfo.name = "مطعم الشرق الأوسط للوجبات الشرقية"، city = "الرياض" | تصدير ناجح بدون قطع نصوص، تخطيط صحيح RTL |
| 2 | **طويل** | محتوى طويل جداً (ملخص، وصف) | executiveSummary.projectOverview = 500+ كلمة، وصف تفصيلي | تصدير ناجح، لا تجاوز حدود الصفحة، تنسيق صحيح |
| 3 | **ناقص** | بيانات ناقصة (حقول فارغة) | projectInfo.name فقط، باقي الحقول فارغة | تصدير ناجح، عرض "—" أو "غير محدد" للحقول الفارغة، لا أخطاء |
| 4 | **أرقام كبيرة** | قيم مالية كبيرة | revenue = 50,000,000، capex = 10,000,000 | تصدير ناجح، تنسيق الأرقام صحيح (فاصلة آلاف)، لا overflow |
| 5 | **أصفار** | قيم صفرية أو سلبية | revenue = 0، npv = -100000 | تصدير ناجح، عرض الأصفار والأرقام السالبة بشكل صحيح |

---

## خطوات التحقق لكل حالة

### الحالة 1 — عربي
- [ ] PDF: النص يظهر RTL، لا انعكاس خاطئ
- [ ] PPTX: الشرائح تعرض العربية بشكل صحيح
- [ ] DOCX: التنسيق RTL صحيح
- [ ] Excel: الأعمدة والصفوف بالعربية

### الحالة 2 — طويل
- [ ] لا قطع في منتصف الكلمة
- [ ] التذييل/الترويسة تظهر بشكل صحيح
- [ ] التمرير أو تقسيم الصفحة يعمل

### الحالة 3 — ناقص
- [ ] لا أخطاء JavaScript (console)
- [ ] لا #REF! أو #VALUE! في Excel
- [ ] رسائل "غير محدد" أو "—" واضحة

### الحالة 4 — أرقام كبيرة
- [ ] تنسيق 50,000,000 (فاصلة آلاف)
- [ ] العملة SAR تظهر بشكل صحيح
- [ ] لا تجاوز لحدود الخلية في Excel

### الحالة 5 — أصفار
- [ ] NPV سالب يظهر بتنسيق صحيح
- [ ] لا قسمة على صفر
- [ ] الرسوم البيانية لا تتعطل

## سيناريو E2E مختصر

```
1. إنشاء مشروع جديد
2. تعبئة الحالة المطلوبة (عربي/طويل/ناقص/كبير/أصفار)
3. الانتقال لخطوة النتائج (لوحة القرار)
4. فتح قائمة التصدير
5. تصدير PDF، PPTX، DOCX، Excel
6. التحقق: الملف يُحمّل، يُفتح بدون أخطاء
```
